# Session 6 — individual exercise

Open this folder in VS Code and run `notebooks/S6_student_exercise.ipynb` using the prepared Python/Jupyter kernel. The first cell starts a local server; do not run the Terminal server at the same time. The page and its JavaScript are in `student/`, with local styling in `shared/`.

Before class, the kernel environment must already contain `pandas`, `requests`, `ipykernel` and `playwright`, plus the Playwright Chromium browser. If only Playwright is missing, use `python -m pip install -r requirements_s6.txt` and then `python -m playwright install chromium` in that same environment before class.

This package contains the exercise, no professor notebook or corrected solution.
