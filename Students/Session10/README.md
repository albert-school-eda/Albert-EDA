# S10 student materials
Keep `notebooks`, `data` and `docs` together. Open `notebooks/S10_student_exercise.ipynb` in VS Code/Jupyter and select your existing course Python environment. Run all cells. All code is supplied; complete the written answers and decision table. Data are synthetic and match the S10 slides. No teacher correction is included.
If needed, install the local dependencies with `python -m pip install -r requirements.txt`. No additional scraping, OCR or browser setup is required.
