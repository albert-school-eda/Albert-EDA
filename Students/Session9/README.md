# S9 — Student exercise

Extract this ZIP and preserve `notebooks/` beside `data/`. Open
`notebooks/S9_student_exercise.ipynb` in VS Code or Jupyter and select your course kernel.
Run setup and loading first; then complete the staged tasks. If needed:
`python -m pip install -r requirements_s9.txt`.

Source: `data/S9_support_requests.csv`, 360 synthetic requests, one quarter, one row per request.
UTF-8, comma separator, decimal point. The notebook contains the full data dictionary.
No external source or network is required. Keep the values unchanged.

Work individually for 35–40 minutes. Submit one page or slide with three evidenced findings,
one recommendation, limitations and a verified AI suggestion. Use the notebook as supporting evidence.
This distribution contains no solution or teacher reference results.
